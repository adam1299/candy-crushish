# Agent entry point

Read `PROGRESS.md` first, then the latest linked `docs/progress/` entry and `docs/DESIGN.md`.
After EVERY implementation milestone:
1. Run the relevant checks and full `node --test` suite.
2. Add a dated, numbered Markdown entry to `docs/progress/` describing changes, files, verification, limitations, and next steps.
3. Update `PROGRESS.md` with the current state and link to that entry.
4. Never describe ad simulations, native project generation, or unbalanced levels as production-ready features.

User direction: Weather Workshop; bright, energetic, dramatic storms and explosions. Android and iOS with desktop browser testing. 100 progressively challenging levels, earned coins, limited paid-with-coins boosters, ads, future real-money advantages.
Use small modules and the Node standard test runner. No backend or real-money purchases in milestone 1. Keep personal credentials, signing files, build products, and node_modules out of Git. Preserve this handoff system for every future change.
